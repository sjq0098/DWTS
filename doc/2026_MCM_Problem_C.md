# 2026 MCM Problem C: Data With The Stars
# 2026年美国大学生数学建模竞赛C题：与星共舞的数据

---

## 一、背景介绍

### 1.1 节目概述

《与星共舞》（Dancing with the Stars，简称DWTS）是美国版的国际电视真人秀节目，改编自英国节目《舞林争霸》（Strictly Come Dancing，原名"Come Dancing"）。该节目的不同版本已在阿尔巴尼亚、阿根廷、澳大利亚、中国、法国、印度等众多国家播出。**本题聚焦的美国版节目已播出34季。**

### 1.2 比赛规则

#### 基本赛制
- **组队形式**：明星与专业舞者组成搭档，每周进行舞蹈表演
- **评委评分**：由专家评审团对每对组合的舞蹈进行评分
- **粉丝投票**：粉丝通过电话或在线方式投票选出当周最喜爱的组合
  - 粉丝每周可投票一次或多次，但需遵守每周公布的投票上限
  - **重要**：粉丝只能为心仪的明星投票（保留票），无法投票淘汰某位明星

#### 淘汰机制
- 评委评分与粉丝投票结果**合并计算**，确定当周淘汰的组合（总分最低者被淘汰）
- 三对组合（部分赛季更多）进入决赛
- 决赛当周综合评委与粉丝的评分，按总分从高到低排名前三（或第四、第五）

### 1.3 投票组合方法的历史演变

#### 方法一：排名法（Rank Method）
- **使用赛季**：第1-2季，第28-34季
- **计算方式**：基于排名进行组合

#### 方法二：百分比法（Percentage Method）
- **使用赛季**：第3-27季
- **产生原因**：第2季出现争议——明星选手Jerry Rice尽管评委评分很低，仍进入决赛
- **计算方式**：用百分比代替排名进行组合

#### 第28季的规则调整
第27季再次出现争议：名人选手Bobby Bones尽管评委评分持续偏低却意外夺冠。为此，从第28季开始对淘汰机制进行了微调：

1. **"底部二选一"规则**：通过综合评委评分与观众票数确定排名最后的两位选手，随后在直播环节由评委投票决定淘汰哪位
2. **恢复排名法**：制作方恢复了第1-2季采用的排名制来组合评委评分与观众票数

> **注**：虽然具体是哪一季实施了这一调整尚不确定，但可以合理推测是第28季的改革。

### 1.4 评分与投票的本质

| 类型 | 目的 | 特点 |
|------|------|------|
| **评委评分** | 体现舞者的技术水平 | 相对客观，但舞蹈优劣的评判标准仍带有一定主观性 |
| **粉丝投票** | 反映观众喜好 | 更具主观性，既取决于舞蹈质量，也受明星人气与魅力影响 |

> **制作方视角**：节目制作方有时甚至偏爱意见分歧和票数争议，因为这类现象能有效激发粉丝的热情与期待，提升节目关注度。

## 二、题目要求

题目提供了包含评委评分与参赛者信息的数据。参赛者可根据自身判断选择是否纳入其他信息或数据，**但必须完整记录数据来源**。

### 要求一：建立粉丝投票估算模型

**核心任务**：建立数学模型（或多个模型），用于估算每位参赛者在比赛期间各周的**预估粉丝票数**（该数据未知且属于严格保密信息）。

需要回答：
1. **一致性验证**：您的模型能否准确预测导致每周淘汰结果一致的粉丝投票？请提供一致性评估指标。
2. **确定性度量**：您所生成的粉丝投票总数具有多少确定性？这种确定性是否在每位参赛者/每周都保持一致？请提供对估计值的确定性度量。

### 要求二：投票组合方法对比与争议分析

将粉丝投票预估数据与其他数据结合使用，完成以下分析：

#### 2.1 跨赛季方法对比
- 对比分析节目采用的两种方法（即**排名法**与**百分比法**）在跨季整合评委与观众投票结果时的表现
- 对每个赛季均应用两种方法进行对比
- 若结果存在差异，分析是否其中一种方法更倾向于偏向观众投票

#### 2.2 争议案例分析
分析两种投票方式在涉及"争议"的明星案例中的应用，即**评委与粉丝意见存在分歧**的情形：

- 若采用不同的评委评分与粉丝票数组合方式，是否会导致不同结果？
- 若增加"底部二选一"规则（评委每周从排名最后的两对选手中进行选择），会对最终结果产生何种影响？

**典型争议案例参考**（可能还有其他案例）：

| 赛季 | 选手 | 争议情况 |
|------|------|----------|
| 第2季 | Jerry Rice | 尽管5周内获得评委最低分，仍斩获**亚军** |
| 第4季 | Billy Ray Cyrus | 6周获得评委最低分，最终排名**第5** |

| 第27季 | Bobby Bones | 评委评分持续偏低，仍成功**夺冠** |

#### 2.3 方法推荐
根据您的分析：
- 推荐在未来赛季中采用哪种方法？为什么？
- 是否建议增加"底部二选一"规则？

### 要求三：影响因素分析模型

利用包含粉丝投票预估的数据，建立模型分析以下因素的影响：

- **职业舞者因素**：不同专业舞伴对比赛结果的影响
- **明星特征因素**：数据中可获得的名人特征（如年龄、行业等）

需要回答：
1. 这些因素对名人参赛表现的影响程度如何？
2. 它们是否以相同方式影响评委评分和粉丝投票？

### 要求四：提出新的投票系统

设计一个每周使用粉丝投票和评委评分的新系统，使其更加：
- **"公平"**（Fair）

需要提供充分的论证，说明为何该方案值得节目制作方采纳。

## 四、数据说明

### 4.1 数据文件

**文件名**：`2026_MCM_Problem_C_Data.csv`

**内容**：第1-34季每周参赛者信息、比赛结果及评委评分

### 4.2 变量说明

| 变量名 | 说明 | 示例 |
|--------|------|------|
| `celebrity_name` | 明星选手姓名 | Jerry Rice, Mark Cuban, ... |
| `ballroom_partner` | 专业舞伴姓名 | Cheryl Burke, Derek Hough, ... |
| `celebrity_industry` | 明星职业分类 | Athlete, Model, ... |
| `celebrity_homestate` | 原籍州（若来自美国） | Ohio, Maine, ... |
| `celebrity_homecountry/region` | 母国/地区 | United States, England, ... |
| `celebrity_age_during_season` | 参赛时年龄 | 32, 29, ... |
| `season` | 节目播出季 | 1, 2, 3, ..., 34 |
| `results` | 赛季成绩描述 | 1st Place, Eliminated Week 2, ... |
| `placement` | 最终排名（1为最佳） | 1, 2, 3, ... |
| `weekX_judgeY_score` | 第X周评委Y的评分 | 1, 2, 3, ... |

### 4.3 数据注释

#### 关于评委评分

1. **评分范围**：评委对每支舞蹈的评分范围为**1分（低）至10分（高）**

2. **小数评分的产生原因**：
   - 在某些周次的评分报告中包含小数（例如8.5）
   - 这是因为每位明星表演了多个舞蹈项目，且各项目得分取**平均值**

3. **奖励积分处理**：
   - 在某些周次中，会颁发额外积分（如舞蹈淘汰赛等）
   - 这些积分会**均匀分配**至评委评分/舞蹈评分中

4. **团队舞蹈评分**：
   - 团队舞蹈得分与每位团队成员的得分取**平均值**

#### 关于评委标识

- 评委名单按舞蹈评分顺序排列
- 因此"评委Y"可能**每周或每季不同**
- 即`judge1`不一定在所有周次/赛季中都是同一个人

## 五、附录说明

题目原文提到在附录（Appendix）中提供了两种投票组合方法（排名法和百分比法）的计算示例。

### 排名法（Rank Method）示例逻辑
- 将评委评分转换为排名 $R^J$
- 将粉丝票数转换为排名 $R^F$
- 组合得分 = $R^J + R^F$
- **得分越低，排名越优**

### 百分比法（Percentage Method）示例逻辑
- 计算评委评分占总评委分的百分比 $P^J$
- 计算粉丝票数占总票数的百分比 $P^F$
- 组合得分 = $P^J + P^F$
- **得分越高，排名越优**
