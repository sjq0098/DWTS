# MCM 2026 Problem C - 问题一：粉丝投票估算建模指南

## 📋 题面要求

**Problem 1: Fan Vote Estimation (粉丝投票估算)**

> Since fan votes are not publicly available, develop a model to estimate fan vote totals for each celebrity during each week of their participation.

由于粉丝投票数据未公开，需要建立模型估算每位选手在参赛期间每周的粉丝投票数。

---

## 🎯 建模目标

估算隐变量 $V_{i,s,t}$：选手 $i$ 在赛季 $s$ 第 $t$ 周的粉丝票数

---

## 📐 方法：分层贝叶斯约束优化

### 整体框架

```
┌─────────────────────────────────────────────────────────────┐
│                    分层贝叶斯结构                            │
│                                                             │
│   赛季层 (Season)  ──▶  周次层 (Week)  ──▶  选手层 (Player) │
│        ↓                    ↓                    ↓          │
│   超参数 α_s          方差 σ²_{s,t}        投票 V_{i,s,t}   │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │     淘汰约束 (Hard Constraint) │
              │  被淘汰选手组合得分必须最低    │
              └───────────────────────────────┘
```

---

## 一、假设条件设定

### （一）基础合理性假设

| 假设 | 内容 |
|------|------|
| **投票非负性与归一化** | 单周内所有选手的粉丝票数占比均为非负实数；同一周内所有未淘汰选手的粉丝票数占比之和为1 |
| **规则一致性** | 同一赛季严格遵循同一投票组合规则（Rank法/Percentage法），淘汰逻辑统一为"单周组合得分最低者被淘汰" |
| **数据有效性** | "0分"严格对应"已淘汰选手后续周次无参赛表现"，缺失值可通过同周其他评委评分均值填充 |
| **评委独立性** | 同一周内不同评委对同一选手的评分相互独立 |

### （二）分层贝叶斯核心假设

| 假设 | 内容 |
|------|------|
| **层级结构** | 粉丝投票存在"赛季→周次→选手"三级嵌套结构 |
| **分布假设** | 粉丝投票量服从**分层对数正态分布**（适配非负性、右偏特性） |
| **特征关联性** | 选手的粉丝投票均值与可观测特征（年龄、行业、舞伴人气等）存在非线性关联 |
| **MCMC有效性** | 后验分布满足"遍历性"，通过足够迭代次数的MCMC采样可逼近真实后验分布 |

### （三）特殊场景假设

- **淘汰后投票无效**：选手被淘汰后，后续周次的粉丝投票视为0
- **多淘汰周**：约束条件扩展为"前k个最低组合得分对应淘汰选手"
- **无淘汰周**：所有选手的组合得分满足"无最低阈值触发"

## 二、核心变量定义

### 层级标识变量

| 变量 | 维度 | 含义 |
|------|------|------|
| $s$ | 整数 (1≤s≤34) | 赛季编号 |
| $t$ | 整数 (≥1) | 赛季s内的比赛周次 |
| $i$ | 整数 (≥1) | 选手编号 |

### 观测变量

| 变量 | 维度 | 含义 |
|------|------|------|
| $J_{i,s,t}$ | 实数 (1≤J≤10) | 选手i在赛季s第t周的评委均分 |
| $E_{s,t}$ | 集合 | 赛季s第t周的淘汰选手集合 |
| $X_i$ | 向量 (维度d) | 选手i的静态特征向量（年龄、行业等） |
| $A_{i,s,t}$ | 整数 (0/1) | 选手i在赛季s第t周的参赛状态 |

### 隐变量（目标）

| 变量 | 维度 | 含义 |
|------|------|------|
| $V_{i,s,t}$ | 非负实数 | **选手i在赛季s第t周的粉丝票数（需估算）** |
| $P_{i,s,t}$ | 实数 (0≤P≤1) | 粉丝票数占比 |

### 派生变量

| 变量 | 含义 | 适用规则 |
|------|------|----------|
| $R^J_{i,s,t}$ | 评委得分排名 | Rank法 |
| $R^V_{i,s,t}$ | 粉丝票数排名 | Rank法 |
| $C^{rank}_{i,s,t}$ | Rank法组合得分 = $R^J + R^V$ | 赛季1-2, 28-34 |
| $C^{pct}_{i,s,t}$ | Percentage法组合得分 | 赛季3-27 |

### 模型参数变量

| 变量 | 含义 |
|------|------|
| $\mu_{i,s,t}$ | 选手i在赛季s第t周粉丝投票对数的均值 |
| $\sigma^2_{s,t}$ | 赛季s第t周粉丝投票对数的方差（周次级参数） |
| $\alpha_s$ | 赛季s的投票热度超参数 |
| $\beta$ | 特征映射系数向量 |

---

## 三、方程/函数推导

### （一）层级结构与先验分布

#### 1. 赛季层超参数先验

$$\alpha_s \sim \text{Gamma}(\text{shape}=2, \text{rate}=1)$$

> Gamma分布适配正实数超参数，覆盖不同赛季热度差异

#### 2. 周次层参数先验

$$\sigma^2_{s,t} \sim \text{Inv-Gamma}(\alpha_s, \alpha_s)$$

> $\alpha_s$ 越大，$\sigma^2_{s,t}$ 的先验越集中，即赛季热度越稳定

#### 3. 选手层投票均值先验（融合特征）

$$\mu_{i,s,t} = \beta^T X_i + \gamma_{s,t}$$

其中：
- $\beta \sim \mathcal{N}(0, \Sigma_\beta)$：特征映射系数
- $\gamma_{s,t} \sim \mathcal{N}(0, \sigma^2_{s,t})$：周次全局偏移项

#### 4. 粉丝投票似然函数

$$V_{i,s,t} \sim \text{LogNormal}(\mu_{i,s,t}, \sigma^2_{s,t})$$

概率密度函数：
$$p(V_{i,s,t} | \mu_{i,s,t}, \sigma^2_{s,t}) = \frac{1}{V_{i,s,t} \sqrt{2\pi\sigma^2_{s,t}}} \exp\left(-\frac{(\ln V_{i,s,t} - \mu_{i,s,t})^2}{2\sigma^2_{s,t}}\right)$$

### （二）组合得分方程

#### Rank法（赛季1-2, 28-34）

$$C^{rank}_{i,s,t} = R^J_{i,s,t} + R^V_{i,s,t}$$

- 得分越低排名越优
- 排名规则：降序排序，得分最高者排名=1

#### Percentage法（赛季3-27）

$$C^{pct}_{i,s,t} = \frac{J_{i,s,t}}{\sum_{j \in S_{s,t}} J_{j,s,t}} + \frac{V_{i,s,t}}{\sum_{j \in S_{s,t}} V_{j,s,t}}$$

- 得分越高排名越优
- $S_{s,t}$ 为赛季s第t周未淘汰选手集合

### （三）后验分布推导

$$p(\Theta | \text{Data}) \propto \underbrace{\prod_{i,s,t} p(V_{i,s,t} | \mu, \sigma^2)}_{\text{似然项}} \times \underbrace{\mathbb{I}(\text{淘汰约束})}_{\text{约束指示}} \times \underbrace{p(\alpha) p(\sigma^2 | \alpha) p(\beta) p(\gamma)}_{\text{先验项}}$$

### （四）弱监督代理目标

用“是否在本周被淘汰/能否挺进下一周”作为训练信号，学习“生存概率”作为粉丝票数的代理强度：
$$S_{i,s,t}=1-\Pr(\text{Elim}_{i,s,t})$$

---

## 四、约束条件

### （一）硬约束（必须满足）

#### 1. 淘汰规则约束 ⭐核心

| 场景 | 约束条件 |
|------|----------|
| **单淘汰周** | $\forall j \in S_{s,t} \setminus E_{s,t}$: $C_{e,s,t} > C_{j,s,t}$ (淘汰选手得分最差) |
| **多淘汰周** | 淘汰组合得分最低的k位 |
| **无淘汰周** | 所有选手得分高于某阈值 |

#### 2. 投票合理性约束

- **非负约束**：$V_{i,s,t} \geq 0$
- **归一化约束**：$\sum_{i \in S_{s,t}} P_{i,s,t} = 1$
- **淘汰后零投票**：若选手在第t周被淘汰，则 $V_{i,s,t'} = 0$ ($\forall t' > t$)

#### 3. 规则一致性约束

- 同一赛季内组合得分计算方式统一
- 评委得分范围：$1 \leq J_{i,s,t} \leq 10$

### （二）软约束（通过先验融入）

| 约束 | 实现方式 |
|------|----------|
| 特征-投票关联 | 通过 $\beta^T X_i$ 引导 |
| 投票方差约束 | $\sigma^2_{s,t} \sim \text{Inv-Gamma}$ |
| 周次连续性 | 同一选手相邻周投票对数差值 ≤ 2 |

### Step 3: 计算淘汰约束惩罚

```python
def compute_elimination_penalty(V, judge_scores, eliminated_idx, method):
    """
    计算淘汰约束的惩罚项
    - 如果淘汰选手的组合得分确实最低 → 返回0
    - 否则 → 返回大负数 (拒绝该样本)
    """
    if method == 'rank':
        combined = compute_rank_score(judge_scores, V)
    else:
        combined = compute_pct_score(judge_scores, V)
    
    # 检查淘汰选手是否得分最差
    elim_score = combined[eliminated_idx]
    others_min = combined[~eliminated_mask].min()
    
    # 惩罚项：淘汰选手得分应该最差
    penalty = -1000 * (elim_score < others_min)  # 违反约束时惩罚
    return penalty
```

## 七、创新点总结

1. **隐变量建模**：将粉丝投票视为隐变量，通过贝叶斯推断估算
2. **约束优化**：将淘汰规则作为硬约束融入模型
3. **特征融合**：利用选手特征构建结构化先验
4. **不确定性量化**：提供置信区间而非单一点估计
