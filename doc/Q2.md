# 2026 MCM Problem C - 问题二：投票组合方法对比与争议分析

## 一、题面（Problem Statement）

### 背景说明

《与星共舞》(DWTS)节目采用两种不同的方法来组合评委评分与粉丝投票：

1. **排名法（Rank Method）**：用于第1-2季和第28-34季
2. **百分比法（Percentage Method）**：用于第3-27季

第27季出现争议事件——Bobby Bones在评委评分持续偏低的情况下仍然夺冠。为此，第28季开始引入"底部二选一"规则：由评委从组合得分最低的两位选手中投票决定淘汰者。

### 具体任务要求

使用估算的粉丝票数与其他数据，完成以下分析：

#### 任务2.1 跨赛季方法对比
- 对比分析节目采用的两种方法（排名法与百分比法）在跨季整合评委与观众投票结果时的表现
- 对每个赛季均应用两种方法进行对比
- 若结果存在差异，分析是否其中一种方法更倾向于偏向观众投票

#### 任务2.2 争议案例分析
分析两种投票方式在涉及"争议"的明星案例中的应用，即评委与粉丝意见存在分歧的情形：
- 若采用不同的投票组合方式，是否会导致不同结果？
- 若增加"底部二选一"规则，会对最终结果产生何种影响？

**典型争议案例：**
- 第2季 - Jerry Rice：尽管5周内获得评委最低分，仍斩获亚军
- 第4季 - Billy Ray Cyrus：6周获得评委最低分，最终排名第5
- 第11季 - Bristol Palin：12次获得最低评委分，最终排名第3
- 第27季 - Bobby Bones：评委评分持续偏低，仍成功夺冠

#### 任务2.3 方法推荐
根据分析结果，推荐在未来赛季中采用哪种方法，并说明理由。同时需评估是否建议继续使用"底部二选一"规则。

## 二、解题思路（Solution Approach）

### 2.1 两种组合方法的数学表达与本质差异

#### 2.1.1 核心计算逻辑

**排名法（Rank Method）**：
$$C_{i,s,t}^{Rank} = R_{i,s,t}^{J} + R_{i,s,t}^{F}$$

- 得分越低排名越优
- 本质是"低通滤波器"，对极端票数不敏感
- 排序有效性指标（基于GREM框架）：
$$NDCG_{Rank} = \sum_{j = 1}^{n}{\frac{g\left( R_{j,s,t}^{Comb} \right)}{\log_{2}(j + 1)}/IDCG}$$
  - 其中 $g(\cdot)$ 为非递减增益函数（取 $g(x) = 1/x$）
  - $IDCG$ 为理想排序的NDCG

**百分比法（Percentage Method）**：
$$C_{i,s,t}^{Percent} = \frac{S_{i,s,t}^{J}}{\sum_{j}S_{j,s,t}^{J}} + \frac{V_{i,s,t}}{\sum_{j}V_{j,s,t}}$$

- 得分越高排名越优
- 本质是"线性放大器"，易受粉丝票数方差主导
- 对应排序有效性指标：
$$NDCG_{Percent} = \sum_{j = 1}^{n}{\frac{g\left( C_{j,s,t}^{Percent} \right)}{\log_{2}(j + 1)}/IDCG}$$
  - 其中 $g(x) = x$

#### 2.1.2 方法偏向性量化

**核心目标**：量化粉丝投票(F)与评委得分(J)对组合排序结果的贡献占比，验证两种方法的粉丝偏向性差异。

##### (1) 核心归因方法：RankSHAP

**特征定义**：将"评委得分（标准化后）"和"粉丝票数（标准化后）"作为两个核心特征。

**RankSHAP计算逻辑**：特征 $k$（$k = F/J$）的归因值为：

$$\varphi_{R}\left( f_{R},\overrightarrow{x},k \right) = \sum_{S \subseteq M\backslash\left\{ k \right\}}^{}{\frac{|S|!\left( m - |S| - 1 \right)!}{m!}\left\lbrack V_{R}\left( f_{R}\left( S \cup \left\{ k \right\},\overrightarrow{x} \right) \right) - V_{R}\left( f_{R}\left( S,\overrightarrow{x} \right) \right) \right\rbrack}$$

其中：
- $M = \{F, J\}$（2个特征）
- $V_{R}(\cdot) = NDCG(\cdot)$（排序有效性度量）
- $S$ 为特征子集
- $m = 2$（特征总数）

**偏向性指标**：
$$Bias = \frac{\varphi_{R}(F)}{\varphi_{R}(F) + \varphi_{R}(J)}$$
- 越接近1越偏向粉丝

**RankSHAP公理验证**：
- **Rank-Efficiency**：$\varphi_{R}(F) + \varphi_{R}(J) = NDCG(f_{R}) - NDCG(f_{R}^{baseline})$
- **Rank-Monotonicity**：验证"粉丝票数边际增益提升时，$\varphi_{R}(F)$ 非递减"

##### (2) 其他差异验证指标

| 指标 | 定义 | 意义 |
|------|------|------|
| 肯德尔秩相关系数 $\tau$ | 两种方法下选手排名的相关系数 | $\tau$ 显著小于1说明两者存在本质分歧 |
| 淘汰结果差异率 $DiffRate$ | $\frac{\sum_{s,t}I(E_{s,t}^{Rank} \neq E_{s,t}^{Percentage})}{T'}$ | 差异率越高，偏向性差异越明显 |
| Fidelity | 归因重构排序与实际排序的肯德尔秩相关系数 | 衡量归因准确性 |
| wFidelity | 加权肯德尔秩相关系数 | 更贴合"淘汰末位"的核心场景 |

### 2.2 争议案例分析：反事实推演

#### 2.2.1 分析步骤

**Step 1: 争议案例筛选**

选手需满足"评委得分排名显著低于最终排名"：
- 单赛季内至少有3周评委得分排名倒数前2
- 最终排名进入前5

**Step 2: 数据提取**

获取争议选手各周的：
- 评委评分 $S_{i,s,t}^{J}$
- 问题一估算的粉丝票数 $V_{i,s,t}$
- 原赛季规则（Rank/Percentage）
- 实际淘汰结果
- 两种组合方法下该选手的RankSHAP值

**Step 3: 机制切换仿真**

1. 遍历34季所有单淘汰周次，记为T个周次
2. 对第s赛季第t周，输入该周所有选手的 $S^J$ 和 $V$
3. 按Rank法计算 $R^J$、$R^F$，得到 $C^{Rank}$，排序后确定模拟淘汰者 $E_{s,t}^{Rank}$
4. 按Percentage法计算 $P^J$、$P^F$，得到 $C^{Percentage}$，排序后确定模拟淘汰者 $E_{s,t}^{Percentage}$

**Step 4: RankSHAP对比**

计算两种方法下争议选手的 $\varphi_{R}^{F}/\varphi_{R}^{J}$ 比值（粉丝-评委贡献比）：
- 若 $\left(\frac{\varphi_{R}^{F}}{\varphi_{R}^{J}}\right)_{Percent} > \left(\frac{\varphi_{R}^{F}}{\varphi_{R}^{J}}\right)_{Rank}$，说明Percentage法更放大粉丝优势

**Step 5: 结果对比**

判断规则切换后争议选手的排名/淘汰状态是否改变：
- 两种方法下RankSHAP值的差异
- 归因有效性（Fidelity ≥ 0.6 视为归因可靠）
- 结合NDCG对比两种方法对争议选手排序的"合理性"

#### 2.2.2 干扰变量控制：倾向得分匹配（PSM）

**目的**：确保两种方法的对比是"净效应"而非外部因素干扰

**协变量（干扰变量）**：
- 赛季参赛人数
- 该周评委得分标准差（反映评委意见分歧）
- 选手平均年龄
- 选手行业分布

**匹配步骤**：
1. 将所有周次按原始规则分为"Rank法组"和"Percentage法组"
2. 用逻辑回归模型计算每个周次的倾向得分
3. 采用1:1最近邻匹配，形成平衡样本
4. 验证两种方法的RankSHAP值分布无显著差异（t检验，$p > 0.05$）

**输出**：平衡样本集（含匹配后的周次对，共 $T'$ 个周次）

### 2.3 "底部二选一"规则仿真

#### 2.3.1 法官投票逻辑

设某周底部两位选手为 $i_1$、$i_2$，法官投票倾向于技术更优者：

$$P(Eliminate = i_1) = \frac{S_{i_2}^{J}}{S_{i_1}^{J} + S_{i_2}^{J}}$$

$$P(Eliminate = i_2) = 1 - P(Eliminate = i_1)$$

> 若 $S_{i_1}^{J} = S_{i_2}^{J}$，则 $P=0.5$，随机淘汰

#### 2.3.2 影响评估指标

对比"直接淘汰末位"与"底部二选一"两种机制：

| 评估维度 | 指标 | 计算方式 |
|----------|------|----------|
| 争议选手晋级率 | $Rate_{new} - Rate_{direct}$ | 两种机制下成功晋级至原最终排名的概率差异 |
| 决赛技术水平 | 评委得分均值 | - |
| 结果悬念度 | 单周组合得分方差 | - |
| 粉丝贡献权重变化 | $\Delta\varphi_{R}^{F} = \|\varphi_{R,new}^{F} - \varphi_{R,direct}^{F}\|/\varphi_{R,direct}^{F}$ | $< 10\%$ 说明规则影响小 |
| 归因有效性变化 | Fidelity/wFidelity提升 | t检验，$p < 0.05$ |

**统计检验**：对所有指标进行配对t检验，$p < 0.05$ 视为差异显著。

## 三、关键优化亮点总结

| 优化点 | 说明 |
|--------|------|
| **方法适配性提升** | 用RankSHAP替换普通SHAP，解决排序任务中归因不满足公理的问题 |
| **评估维度丰富** | 融入NDCG（排序质量）、Fidelity/wFidelity（归因有效性），形成闭环验证 |
| **争议分析深化** | 通过 $\varphi_{R}^{F}/\varphi_{R}^{J}$ 比值精准定位争议产生的核心原因 |
| **规则调节量化** | 用RankSHAP值变化率衡量"底部二选一"规则对权重的影响 |
