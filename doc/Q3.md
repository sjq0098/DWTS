# 2026 MCM Problem C - 问题三：特征影响分析

## 一、题面（Problem Statement）

### 原题要求

> Use the data including your fan vote estimates to develop a model that analyzes the impact of various pro dancers as well as characteristics for the celebrities available in the data (age, industry, etc). How much do such things impact how well a celebrity will do in the competition? Do they impact judges scores and fan votes in the same way?

### 中文翻译

利用包含粉丝投票预估的数据，建立一个模型来分析以下因素的影响：
- **职业舞者因素**：不同专业舞伴对比赛结果的影响
- **明星特征因素**：数据中可获得的名人特征（如年龄、行业等）

### 核心问题

1. **影响程度量化**：这些因素对名人参赛表现的影响程度如何？
2. **影响差异对比**：它们是否以相同方式影响评委评分和粉丝投票？

### 可用数据特征

| 变量名 | 说明 | 类型 |
|--------|------|------|
| `celebrity_age_during_season` | 参赛时年龄 | 连续变量 |
| `celebrity_industry` | 明星职业分类 | 类别变量 |
| `celebrity_homestate` | 原籍州（美国） | 类别变量 |
| `celebrity_homecountry/region` | 母国/地区 | 类别变量 |
| `ballroom_partner` | 专业舞伴姓名 | 类别变量 |
| `season` | 节目播出季 | 连续/类别变量 |
| `weekX_judgeY_score` | 各周评委评分 | 连续变量 |
| 粉丝投票估算值（问题一） | 各周粉丝票数 | 连续变量 |

## 二、解题思路（Solution Approach）

### 总体框架

采用 **“XGBoost回归 + TreeSHAP/RankSHAP归因”** 框架：
- 以评委得分与粉丝投票为回归目标，建模非线性关系
- TreeSHAP解释“预测值”层面的特征重要性
- RankSHAP解释“排序质量(NDCG)”层面的特征贡献
- 对比评委与粉丝偏好差异

### 2.2 核心建模：XGBoost

#### 2.2.1 模型选择理由

| 优势 | 说明 |
|------|------|
| 非线性捕捉 | 适配高维非线性数据 |
| 自动交互 | 能自动捕捉特征交互效应 |
| 正则化 | 支持正则化防过拟合 |
| 混合特征 | 能高效处理混合类型特征（连续+类别） |
| 性能优越 | 优于传统线性回归 |

#### 2.2.2 目标函数

代码实现为**回归任务**：
- 评委得分：`reg:squarederror`
- 粉丝投票：`reg:squarederror`

#### 2.2.3 正则化参数

| 参数 | 初始值 | 作用 |
|------|--------|------|
| $\gamma$（叶子节点数惩罚） | 0.1 | 控制树的复杂度 |
| $\lambda$（权重惩罚） | 1.0 | 控制模型复杂度 |
| `max_depth`（树深度） | 5 | 避免过深导致过拟合 |
| `learning_rate`（学习率） | 0.05 | 平衡训练速度与模型精度 |

#### 2.2.4 其他参数

| 参数 | 值 | 作用 |
|------|-----|------|
| `subsample`（子样本比例） | 0.8 | 随机采样训练样本，提升泛化能力 |
| `colsample_bytree`（列采样比例） | 0.8 | 随机选择特征构建每棵树，减少特征相关性干扰 |

#### 2.2.5 模型训练流程

**Step 1: 数据划分**
- 按 **7:3** 拆分训练/测试
- 以“`season + celebrity_name`”为分组键，确保同一选手所有周次不跨集合

**Step 2: 超参数调优**
- 方法：5折交叉验证 + 网格搜索
- 搜索范围：

| 参数 | 搜索范围 |
|------|----------|
| `max_depth` | [3, 5, 7] |
| $\gamma$ | [0.01, 0.1, 1.0] |
| `learning_rate` | [0.01, 0.05, 0.1] |
| `n_estimators` | [100, 200, 300] |

**Step 3: 模型训练**
- 基于最优参数训练最终模型
- 记录训练集与验证集的拟合效果

### 2.3 RankSHAP归因分析（与代码一致）

#### 2.3.1 排序有效性度量：NDCG

采用 **NDCG（Normalized Discounted Cumulative Gain）** 作为核心价值函数（GREM框架实例）：

$$NDCG_n = \frac{\sum_{j=1}^{n} \frac{rel_j}{\log_2(j+1)}}{IDCG_n}$$

其中：
- $rel_j$：选手"综合表现得分"（融合评委得分与粉丝投票）
- $j$：排名位置
- $IDCG_n$：理想排序下的DCG值

**设计目的**：确保归因同时考虑"表现相关性"和"排名位置权重"

#### 2.3.2 归因计算实现：Permutation RankSHAP（代码实现）

实际实现为**按“赛季-周次”分组的排列重要性**：
1. 以 `season_week` 为组，组内存在多名选手才能计算排序
2. 对每个特征进行多次随机打乱（默认10次）
3. 计算打乱前后 NDCG 的下降量，作为该特征的边际贡献
4. 对所有组的贡献取均值，得到全局 RankSHAP

注：`season` 与 `week` 在同一`season_week`组内为常量，打乱不会改变排序，
因此 RankSHAP 贡献为 0（图8中已标注“const”）。

#### 2.3.3 三维归因分析

##### (1) 个体归因

计算每个选手各特征的RankSHAP值，明确该特征对其比赛表现的正向/负向贡献：
- **RankSHAP > 0**：该特征提升选手排名（或得分）
- **RankSHAP < 0**：该特征降低排名

**应用示例**：针对争议选手（如Bobby Bones），可明确其"演员行业""舞伴人气"等特征对排名的正向贡献，解释**低评委分仍高排名的核心原因**。

##### (2) 全局影响

通过标准化RankSHAP值绝对值的均值，量化各特征的全局影响强度：

$$GlobalImpact(f) = \frac{mean(|RankSHAP(f, x_i)|)}{\sum_{f'} mean(|RankSHAP(f', x_i)|)}$$

**解读**：数值越大，特征对排名/得分的整体影响越显著

##### (3) 偏好差异对比

对比同一特征对"评委得分"与"粉丝投票"的影响强度，揭示偏好冲突。

**影响强度比**：
$$Ratio(f) = \frac{GlobalImpact_{粉丝}(f)}{GlobalImpact_{评委}(f)}$$

**差异判定标准**：

| Ratio(f) 范围 | 解读 |
|---------------|------|
| > 1.5 | 特征对**粉丝投票**影响更显著 |
| < 0.5 | 特征对**评委评分**影响更显著 |
| 0.5 ~ 1.5 | 对两者影响相近 |

**预期发现示例**：
- 演员行业对粉丝投票影响更大
- 年龄对评委评分更敏感

## 四、方法优势总结

| 优势 | 说明 |
|------|------|
| **非线性建模** | XGBoost能捕捉复杂的非线性关系，优于传统线性模型 |
| **可解释性** | RankSHAP提供特征级别的归因解释，满足题目"量化影响程度"的要求 |
| **排序专属** | 采用NDCG作为价值函数，适配比赛排名的本质特性 |
| **双目标对比** | 分别建模评委得分与粉丝投票，直接回答"是否以相同方式影响"的问题 |
| **公理保证** | RankSHAP满足Rank-Efficiency等公理，确保归因结果的理论合理性 |
