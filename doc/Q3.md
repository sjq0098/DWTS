# 2026 MCM Problem C - 问题三：特征影响分析

## 一、题面（Problem Statement）

### 原题要求

> Use the data including your fan vote estimates to develop a model that analyzes the impact of various pro dancers as well as characteristics for the celebrities available in the data (age, industry, etc). How much do such things impact how well a celebrity will do in the competition? Do they impact judges scores and fan votes in the same way?

### 中文翻译

利用包含粉丝投票预估的数据，建立一个模型来分析以下因素的影响：
- **职业舞者因素**：不同专业舞伴对比赛结果的影响
- **明星特征因素**：数据中可获得的名人特征（如年龄、行业等）

### 核心问题

1. **影响程度量化**：这些因素对名人参赛表现的影响程度如何？
2. **影响差异对比**：它们是否以相同方式影响评委评分和粉丝投票？

### 可用数据特征

| 变量名 | 说明 | 类型 |
|--------|------|------|
| `celebrity_age_during_season` | 参赛时年龄 | 连续变量 |
| `celebrity_industry` | 明星职业分类 | 类别变量 |
| `celebrity_homestate` | 原籍州（美国） | 类别变量 |
| `celebrity_homecountry/region` | 母国/地区 | 类别变量 |
| `ballroom_partner` | 专业舞伴姓名 | 类别变量 |
| `season` | 节目播出季 | 连续/类别变量 |
| `weekX_judgeY_score` | 各周评委评分 | 连续变量 |
| 粉丝投票估算值（问题一） | 各周粉丝票数 | 连续变量 |

---

## 二、解题思路（Solution Approach）

### 总体框架

采用 **"XGBoost（梯度提升树）+ RankSHAP"** 框架：
- 捕捉选手特征、专业舞伴等因素与比赛表现（评委得分、粉丝投票、最终排名）的**非线性关联**
- 通过归因分析明确各因素的**影响强度与方向**
- 对比其对**评委与粉丝的偏好差异**

---

### 2.1 特征工程设计

#### 特征分类与处理方式

| 特征类型 | 具体内容 | 处理方式 |
|----------|----------|----------|
| **显性特征** | 年龄（`celebrity_age_during_season`） | 标准化：$age_{norm} = \frac{age - mean(age)}{std(age)}$ |
| | 行业（`celebrity_industry`） | One-hot编码，避免类别序数偏见 |
| | 国籍/地区（`celebrity_homecountry/region`） | One-hot编码，合并小众地区为"Other"类别 |
| **隐性特征** | 专业舞伴人气 | 按舞伴历史赛季平均排名分类：高人气（前30%）→2，普通→1，新人→0 |
| | 舞伴合作次数 | 统计同一选手与舞伴的合作季数，作为连续变量 |
| | 选手过往曝光度 | 全明星季（第15季）选手→2，其他按过往参赛次数编码 |
| **时间特征** | 赛季年份（`season`） | 作为连续变量，捕捉趋势变化 |
| | 比赛周次（`week`） | 作为连续变量，反映赛程进展 |
| **交互特征** | 年龄×行业 | $age\_industry = age_{norm} \times onehot(industry)$ |
| | 舞伴×行业 | $partner\_industry = partner\_popularity \times onehot(industry)$ |

### 2.2 核心建模：XGBoost

#### 2.2.1 模型选择理由

| 优势 | 说明 |
|------|------|
| 非线性捕捉 | 适配高维非线性数据 |
| 自动交互 | 能自动捕捉特征交互效应 |
| 正则化 | 支持正则化防过拟合 |
| 混合特征 | 能高效处理混合类型特征（连续+类别） |
| 性能优越 | 优于传统线性回归 |

#### 2.2.2 目标函数

根据因变量类型选择损失函数：
- **回归任务**（预测评委得分/粉丝票数）：均方误差 MSE
- **排序任务**（预测最终排名）：pairwise损失

#### 2.2.3 正则化参数

| 参数 | 初始值 | 作用 |
|------|--------|------|
| $\gamma$（叶子节点数惩罚） | 0.1 | 控制树的复杂度 |
| $\lambda$（权重惩罚） | 1.0 | 控制模型复杂度 |
| `max_depth`（树深度） | 5 | 避免过深导致过拟合 |
| `learning_rate`（学习率） | 0.05 | 平衡训练速度与模型精度 |

#### 2.2.4 其他参数

| 参数 | 值 | 作用 |
|------|-----|------|
| `subsample`（子样本比例） | 0.8 | 随机采样训练样本，提升泛化能力 |
| `colsample_bytree`（列采样比例） | 0.8 | 随机选择特征构建每棵树，减少特征相关性干扰 |

#### 2.2.5 模型训练流程

**Step 1: 数据划分**
- 按 **7:3** 比例拆分训练集与测试集
- **关键**：确保拆分时保持"赛季-选手"的完整性（同一选手的所有周次样本同属训练集或测试集，避免数据泄露）

**Step 2: 超参数调优**
- 方法：5折交叉验证 + 网格搜索
- 搜索范围：

| 参数 | 搜索范围 |
|------|----------|
| `max_depth` | [3, 5, 7] |
| $\gamma$ | [0.01, 0.1, 1.0] |
| `learning_rate` | [0.01, 0.05, 0.1] |
| `n_estimators` | [100, 200, 300] |

**Step 3: 模型训练**
- 基于最优参数训练最终模型
- 记录训练集与验证集的拟合效果

### 2.3 RankSHAP归因分析

#### 2.3.1 排序有效性度量：NDCG

采用 **NDCG（Normalized Discounted Cumulative Gain）** 作为核心价值函数（GREM框架实例）：

$$NDCG_n = \frac{\sum_{j=1}^{n} \frac{rel_j}{\log_2(j+1)}}{IDCG_n}$$

其中：
- $rel_j$：选手"综合表现得分"（融合评委得分与粉丝投票）
- $j$：排名位置
- $IDCG_n$：理想排序下的DCG值

**设计目的**：确保归因同时考虑"表现相关性"和"排名位置权重"

#### 2.3.2 归因计算实现：Kernel-RankSHAP

采用 **Kernel-RankSHAP** 近似方法（解决Exact RankSHAP的NP难问题）

**核心逻辑**：
1. 构建线性替代模型拟合XGBoost的排序输出
2. 损失函数定义为：
$$L = \sum_{\vec{z} \in Z} \left[ NDCG(f_R(\vec{z})) - NDCG(g(\vec{z})) \right]^2 \cdot \pi_{\vec{x}}(\vec{z})$$

**采样策略**：
- 每样本生成 **5000个特征子集**（coalitions）
- 通过Kernel权重分配降低高维特征的采样噪声

#### 2.3.3 三维归因分析

##### (1) 个体归因

计算每个选手各特征的RankSHAP值，明确该特征对其比赛表现的正向/负向贡献：
- **RankSHAP > 0**：该特征提升选手排名（或得分）
- **RankSHAP < 0**：该特征降低排名

**应用示例**：针对争议选手（如Bobby Bones），可明确其"演员行业""舞伴人气"等特征对排名的正向贡献，解释**低评委分仍高排名的核心原因**。

##### (2) 全局影响

通过标准化RankSHAP值绝对值的均值，量化各特征的全局影响强度：

$$GlobalImpact(f) = \frac{mean(|RankSHAP(f, x_i)|)}{\sum_{f'} mean(|RankSHAP(f', x_i)|)}$$

**解读**：数值越大，特征对排名/得分的整体影响越显著

##### (3) 偏好差异对比

对比同一特征对"评委得分"与"粉丝投票"的影响强度，揭示偏好冲突。

**影响强度比**：
$$Ratio(f) = \frac{GlobalImpact_{粉丝}(f)}{GlobalImpact_{评委}(f)}$$

**差异判定标准**：

| Ratio(f) 范围 | 解读 |
|---------------|------|
| > 1.5 | 特征对**粉丝投票**影响更显著 |
| < 0.5 | 特征对**评委评分**影响更显著 |
| 0.5 ~ 1.5 | 对两者影响相近 |

**预期发现示例**：
- 演员行业对粉丝投票影响更大
- 年龄对评委评分更敏感

### 2.4 模型验证

#### 2.4.1 拟合效果验证

| 指标 | 说明 | 目标 |
|------|------|------|
| 调整后 $R^2$ | 判断模型拟合质量 | 越高越好 |
| 残差分析 | 检验残差是否随机分布 | 无系统性偏差 |
| Fidelity | 归因重构排名与实际排名的肯德尔秩相关系数（$\tau$） | ≥ 0.7 |
| wFidelity | 加权肯德尔秩相关系数（惩罚高位排名偏差） | ≥ 0.65 |

#### 2.4.2 稳健性验证

| 验证方法 | 说明 |
|----------|------|
| K折交叉验证 | 检验模型在不同数据子集上的表现，避免过拟合（保留10折交叉验证） |
| 公理合规性验证 | 检查RankSHAP归因是否满足 **Rank-Efficiency**（特征归因和 = NDCG差值），确保归因逻辑自洽 |

#### 2.4.3 多重共线性检验

- 方法：**VIF检验**（方差膨胀因子）
- 标准：**VIF < 10**
- 目的：排除特征间强相关性干扰，确保归因结果可靠

### 2.5 可视化建议

#### 图表1：RankSHAP蜂群图（Beeswarm Plot）
- **内容**：展示各特征RankSHAP值分布
- **作用**：突出排名敏感特征的影响差异
- **横轴**：RankSHAP值
- **纵轴**：特征名称
- **颜色**：特征值高低

#### 图表2：排名归因热力图（Heatmap）
- **维度**：选手排名位置 × 特征
- **内容**：呈现特征对不同排名区间选手的影响强度
- **作用**：识别哪些特征对冠军/淘汰选手影响最大

#### 图表3：评委vs粉丝影响对比图
- **类型**：分组柱状图或雷达图
- **内容**：对比各特征对评委得分与粉丝投票的GlobalImpact值
- **作用**：直观展示偏好差异
